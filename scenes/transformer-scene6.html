Query, Key, and Value: The Information Lookup

Inspired by database retrieval: matching queries to keys to extract weighted values

Q
Query Vector

"What information am I looking for?"

Represents the current token searching for relevant context.

Q = X · W_Q
K
Key Vector

"What content do I have to offer?"

Acts as the address label that Queries match against.

K = X · W_K
V
Value Vector

"What actual meaning do I deliver?"

The substantive representation that gets weighted and retrieved.

V = X · W_V
Attention(Q, K, V) = softmax( (Q · Kᵀ) / √d_k ) · V
